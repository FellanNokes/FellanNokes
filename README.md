## Projects
 
### Marathos Data Platform
- **[Marathos Data Platform](https://github.com/FellanNokes/marathos_felix_kjellberg)**  
  End-to-end data platform built on **Databricks** following a medallion architecture (Bronze → Silver → Gold). Ingests two centuries of ultra-marathon race data, cleans it via a **PySpark** streaming pipeline, and models it into a dimensional model (`fct_results`, `dim_athlete`, `dim_event`, `dim_date`). Includes a Databricks dashboard and **Genie** AI assistant for natural language querying.  
  *Stack: Databricks, PySpark, Python, Plotly, Git*
